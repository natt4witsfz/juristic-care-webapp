# แบบฟอร์มรับแจ้งงาน Juristic Care

## ชื่อฟอร์ม
Juristic Care - แจ้งปัญหา / แจ้งซ่อม / งานนิติบุคคล

## คำอธิบายฟอร์ม
ใช้สำหรับแจ้งปัญหาภายในห้องพัก พื้นที่ส่วนกลาง และงานที่ต้องให้นิติบุคคลตรวจสอบ ข้อมูลจะถูกส่งเข้า Pool งานกลางเพื่อคัดแยกประเภทและมอบหมายผู้รับผิดชอบ

## โครงสร้างคำถาม

### 1. ข้อมูลผู้แจ้ง
1. ชื่อผู้แจ้ง
   - ประเภท: คำตอบสั้น
   - จำเป็น: ใช่

2. เลขห้อง / พื้นที่ที่เกี่ยวข้อง
   - ประเภท: คำตอบสั้น
   - ตัวอย่าง: A-1204, Lobby, ชั้น 8, Parking B1
   - จำเป็น: ใช่

3. เบอร์โทรศัพท์
   - ประเภท: คำตอบสั้น
   - จำเป็น: ใช่

4. ช่องทางติดต่อเพิ่มเติม
   - ประเภท: คำตอบสั้น
   - ตัวอย่าง: LINE ID, อีเมล
   - จำเป็น: ไม่

### 2. ประเภทงาน
5. ประเภทหลัก
   - ประเภท: ตัวเลือกเดียว
   - ตัวเลือก:
     - งานส่วนกลาง
     - งานลูกบ้าน
   - จำเป็น: ใช่

6. ประเภทรอง
   - ประเภท: รายการแบบเลื่อนลง
   - ตัวเลือก:
     - ปะปา
     - ไฟฟ้า
     - ความสะอาด
     - โครงสร้างอาคาร
     - ลิฟต์
     - สวน
     - เฟอร์นิเจอร์
     - ระบบความปลอดภัย
     - อินเตอร์เน็ต
   - จำเป็น: ใช่

7. ระดับความเร่งด่วน
   - ประเภท: ตัวเลือกเดียว
   - ตัวเลือก:
     - ปกติ
     - เร่งด่วน
     - ฉุกเฉิน
   - จำเป็น: ใช่

### 3. รายละเอียดงาน
8. หัวข้องาน / ปัญหาที่พบ
   - ประเภท: คำตอบสั้น
   - จำเป็น: ใช่

9. รายละเอียดเพิ่มเติม
   - ประเภท: ย่อหน้า
   - คำแนะนำ: ระบุจุดที่เกิดเหตุ อาการที่พบ ช่วงเวลาที่สะดวกให้ติดต่อ หรือข้อมูลที่ช่างควรรู้
   - จำเป็น: ใช่

10. จุดเกิดเหตุ
   - ประเภท: คำตอบสั้น
   - ตัวอย่าง: ห้องน้ำ, ใต้ซิงค์, หน้าลิฟต์ชั้น 8, สวนด้านหน้า
   - จำเป็น: ไม่

11. วันที่พบปัญหา
   - ประเภท: วันที่
   - จำเป็น: ไม่

12. เวลาที่พบปัญหา
   - ประเภท: เวลา
   - จำเป็น: ไม่

### 4. รูปภาพและเอกสารแนบ
13. แนบรูปภาพ / เอกสารประกอบ
   - ประเภท: อัปโหลดไฟล์
   - จำกัดจำนวนที่แนะนำ: สูงสุด 5 ไฟล์
   - ประเภทไฟล์ที่แนะนำ: รูปภาพ, PDF
   - จำเป็น: ไม่

หมายเหตุ: Google Forms อาจต้องให้ผู้ตอบลงชื่อเข้าใช้ Google ก่อนอัปโหลดไฟล์ หากไม่ต้องการบังคับ login ให้ใช้คำถามแบบ "ลิงก์รูปภาพ/ไฟล์" แทน

14. ลิงก์รูปภาพหรือไฟล์เพิ่มเติม
   - ประเภท: ย่อหน้า
   - จำเป็น: ไม่

### 5. การยินยอมและการเปิดเผย
15. อนุญาตให้เจ้าหน้าที่ติดต่อกลับ
   - ประเภท: ตัวเลือกเดียว
   - ตัวเลือก:
     - อนุญาต
     - ไม่อนุญาต
   - จำเป็น: ใช่

16. อนุญาตให้เจ้าหน้าที่เข้าตรวจสอบพื้นที่หรือเข้าห้องตามนัดหมาย
   - ประเภท: ตัวเลือกเดียว
   - ตัวเลือก:
     - อนุญาต
     - ต้องโทรนัดหมายก่อนเท่านั้น
     - ไม่อนุญาต
   - จำเป็น: ใช่

17. การแสดงผลในภาพรวมของโครงการ
   - ประเภท: ตัวเลือกเดียว
   - ตัวเลือก:
     - แสดงเป็นสถิติเท่านั้น
     - อนุญาตให้แสดงรายละเอียดโดยไม่เปิดเผยข้อมูลส่วนตัว
   - จำเป็น: ใช่

## Logic หลังรับคำตอบ

- ทุกคำตอบใหม่เข้า Pool งานกลางก่อน
- หากเลือกประเภทหลักเป็น "งานส่วนกลาง"
  - แสดงใน Sidebar งานส่วนกลาง
  - เมื่อมอบหมายแล้ว แสดงใน Sidebar แผนกของผู้รับมอบหมาย
  - แสดงใน Sidebar งานของฉันของผู้ได้รับมอบหมาย
- หากเลือกประเภทหลักเป็น "งานลูกบ้าน"
  - ไม่แสดงรายละเอียดใน Sidebar งานส่วนกลาง
  - นับรวมในภาพรวมเป็นตัวเลขสถิติ
  - เมื่อมอบหมายแล้ว แสดงใน Sidebar แผนกของผู้รับมอบหมาย
  - แสดงใน Sidebar งานของฉันของผู้ได้รับมอบหมาย
