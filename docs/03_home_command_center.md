# O83 Care - Home Command Center

Version: 1.0

---

# Purpose

Home Command Center คือหน้าหลักของระบบ O83 Care

หน้าจอนี้ไม่ได้ถูกออกแบบมาเพื่อแสดงข้อมูลทั้งหมดของระบบ

แต่ถูกออกแบบมาเพื่อให้ผู้ใช้งานสามารถรับรู้สถานการณ์ของโครงการภายในเวลาไม่เกิน 10 วินาที

ผู้ใช้งานควรรู้ทันทีว่า

- วันนี้มีเรื่องสำคัญอะไร
- งานส่วนกลางดำเนินไปถึงไหน
- เรื่องใดต้องเร่งดำเนินการ
- โครงการมีประกาศอะไรที่ยังมีผล
- สถานะของหน่วยงานภายในเป็นอย่างไร

---

# Design Philosophy

Home ต้องตอบคำถามของผู้ใช้

ไม่ใช่แสดงข้อมูลของระบบ

ผู้ใช้งานไม่ควรเสียเวลาค้นหาข้อมูล

แต่ระบบต้องนำข้อมูลสำคัญมาแสดงก่อน

---

# UX Principle

ผู้ใช้งานต้องสามารถรับรู้สถานการณ์ของโครงการภายในเวลาไม่เกิน 10 วินาที

หากต้องค้นหาข้อมูลหลายขั้นตอน

ถือว่า Home ยังออกแบบได้ไม่ดีพอ

# Home Layout

## 1. Property Overview

แสดงภาพรวมของโครงการ

ตัวอย่าง

- งานทั้งหมด
- งานเปิด
- งานเสร็จวันนี้
- งานเกินกำหนด
- งานรอตรวจสอบ
- งาน On Hold

ข้อมูลแสดงในรูปแบบตัวเลขและกราฟ

---

## 2. Strategic Operations Board

ส่วนนี้เป็นหัวใจของหน้า Home

ใช้แสดงเฉพาะ "งานส่วนกลาง"

ตัวอย่าง

- ซ่อมแอร์ส่วนกลาง
- ปรับปรุงบ่อบำบัด
- ติดตั้งเสาสัญญาณ
- งานผู้รับเหมา
- งานที่เกี่ยวข้องกับพื้นที่ส่วนกลาง
- งานที่มีผลกระทบต่อทั้งโครงการ

ไม่แสดง

- งานแจ้งซ่อมห้องพัก
- งานประจำของแม่บ้าน
- งานประจำของ รปภ.
- งานเฉพาะของแต่ละแผนก

Board แสดงแบบ Kanban

NEW

↓

ASSIGNED

↓

IN PROGRESS

↓

WAITING

↓

VERIFY

↓

DONE

## 3. Active Notices

แสดงประกาศที่ยังมีผลอยู่

ตัวอย่าง

ประกาศทุกฉบับต้องกำหนด

- วันที่สิ้นสุด
- กลุ่มผู้รับสาร

เมื่อหมดอายุ

# Kanban Board Principle

Kanban ใช้สำหรับแสดง "การเดินทางของงาน"

ไม่ใช่ใช้เปลี่ยนสถานะงาน

การเปลี่ยนสถานะต้องดำเนินผ่าน Workflow อย่างเป็นทางการ

โดยต้องมี

- รายละเอียด
- หมายเหตุ
- รูปภาพ
- วิดีโอ (ถ้ามี)
- หลักฐาน
- ผู้ดำเนินการ
- วันและเวลา

ก่อนกดยืนยัน

ทุกการเปลี่ยนสถานะต้องถูกบันทึกลง Audit Log

---

# Kanban Card

Card มีหน้าที่แสดงข้อมูลสรุป

สามารถ

- เปิดรายละเอียด
- ดู Timeline
- ดูไฟล์แนบ

ไม่สามารถ

- Drag & Drop เปลี่ยนสถานะ
- Upload รูป
- มอบหมายงาน
- เปลี่ยนข้อมูลสำคัญ

---

# Priority

ระบบต้องแสดงระดับความสำคัญของงานอย่างชัดเจน

ตัวอย่าง

🚨 Emergency

🔴 Critical

🟠 High

🟡 Normal

🟢 Low

Priority ใช้สำหรับการตัดสินใจ

ไม่ใช่การจัดอันดับ

# Final Principle

Home Command Center

ต้องทำให้ผู้ใช้งานสามารถรับรู้

- สถานการณ์ของโครงการ
- ความคืบหน้าของงาน
- เรื่องเร่งด่วน
- ประกาศสำคัญ
- ความพร้อมของหน่วยงาน
