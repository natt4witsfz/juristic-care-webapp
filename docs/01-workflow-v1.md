# Juristic Care - Workflow V1

## เป้าหมายของ V1

ทำระบบแจ้งซ่อมให้ใช้งานจริงได้ก่อน โดยโฟกัสเฉพาะงานหลัก:

รับแจ้ง → มอบหมาย → ช่างดำเนินการ → นิติตรวจสอบ → แจ้งลูกบ้าน → ปิดงาน

## ช่องทางรับงาน

1. Google Form
2. นิติรับแจ้ง
3. ช่างพบระหว่างตรวจประจำวัน

ทุกช่องทางต้องสร้างเป็น Work Order กลางก่อน

## สถานะหลัก

- NEW
- ASSIGNED
- IN_PROGRESS
- PENDING_VERIFICATION
- PENDING_RESIDENT_NOTIFICATION
- ON_HOLD
- CLOSED
- REJECTED

## Main Flow

NEW
→ ASSIGNED
→ IN_PROGRESS
→ PENDING_VERIFICATION
→ PENDING_RESIDENT_NOTIFICATION
→ CLOSED

## On Hold Flow

IN_PROGRESS
→ ON_HOLD
→ ASSIGNED หรือ IN_PROGRESS

## ความหมายของสถานะ

### NEW
งานใหม่ รอหัวหน้าช่างหรือนิติมอบหมาย

### ASSIGNED
งานถูกมอบหมายให้ช่างแล้ว แต่ยังไม่เริ่มดำเนินการ

### IN_PROGRESS
ช่างรับงานและกำลังดำเนินการ

### PENDING_VERIFICATION
ช่างแจ้งว่าเสร็จแล้ว รอนิติตรวจสอบ พร้อมแนบรูป/วิดีโอ

### PENDING_RESIDENT_NOTIFICATION
นิติตรวจผ่านแล้ว รอแจ้งลูกบ้าน

### ON_HOLD
งานพักไว้ เพราะรออะไหล่ รอผู้รับเหมา รออนุมัติ หรือรอติดตาม

### CLOSED
ปิดงานสมบูรณ์แล้ว ต้องมีหลักฐานแจ้งลูกบ้าน

### REJECTED
นิติตีกลับให้ช่างแก้ไขหรืออัปเดตใหม่

## กติกาสำคัญ

1. ทุกงานต้องมีเจ้าของงานปัจจุบัน
2. ทุกงานต้องรู้ว่าต้องทำอะไรต่อ
3. ถ้างานเสร็จ ต้องมีรูปหลักฐาน
4. ถ้าปิดงาน ต้องมีหลักฐานว่าแจ้งลูกบ้านแล้ว
5. ถ้า ON_HOLD ต้องมีวันที่ติดตามครั้งถัดไป
6. เมื่อถึงวันที่ติดตาม ระบบต้องเด้งกลับมาที่นิติผู้รับผิดชอบ

## หลักฐานแนบไฟล์

ช่างส่งงาน:
- รูปภาพไม่เกิน 4 รูป
- วิดีโอไม่เกิน 1 นาที
- หมายเหตุ

นิติปิดงาน:
- ต้องแนบรูปหลักฐานการแจ้งลูกบ้าน

นิติพักงาน ON_HOLD:
- ต้องแนบหลักฐาน เช่น ใบเสนอราคา แชทผู้รับเหมา หลักฐานสั่งซื้อ หรือเอกสารขออนุมัติ
- ต้องเลือกวันที่คาดว่าจะอัปเดต
