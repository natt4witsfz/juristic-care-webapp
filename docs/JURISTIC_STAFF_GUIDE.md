# Juristic Staff Guide

Record each incoming report as a separate Case, even when several residents describe the same symptom. Correct obvious location selection through a traceable revision or context assertion; never erase the original report.

Start an Investigation to compare location, asset, component, symptom, elapsed time, prior work, hypotheses, and evidence. Link Cases to an Incident only after accountable human verification. Create Operations for the work needed to address the verified Incident, keeping Responsibility, Authority, Commitment, Capability, Availability, Priority, sequence, SLA, due date, verification, and approval separate.

Communicate receipt, access requests, safety notices, progress, completion submission, verification outcome, follow-up, and closure according to audience and privacy. A resident dispute adds evidence and a decision point; it does not silently overwrite completion.

The current application supports secure intake and read projections but not the complete staff workflow. Follow the known limitations and do not use the prototype as the sole operational record.
